# ms2-produit-offreTouristique (frontend)

Interface du microservice **Produits & Offres touristiques** : le catalogue public.

- `accueil/` : page d'accueil (recherche, expériences à la une, destinations)
- `sections/` : pages de contenu du menu (The Camp, Trips, Accommodation, Experiences, Activities). Le texte est dans `sections.data.ts`

À venir : fiche détaillée d'un produit, liste des offres, gestion « Mes produits / Mes offres » du prestataire.
