# ms1-users (frontend)

Interface du microservice **Utilisateurs** : authentification et comptes.

- `se-connecter/` : page de connexion
- `signup/` : inscription (touriste ou prestataire)
- `session.ts` : gestion de session et déconnexion (à brancher sur l'API d'authentification)
- `auth-layout.scss` : style commun des pages d'authentification

À venir : profil, gestion des utilisateurs (admin).
